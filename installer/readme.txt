# おおっと！
このファイルを読んでいるという事は、MODを直接導入しようとして解凍してしまったという事ですね？
このファイルはFomodインストーラーと呼ばれるものであり、残念ながら直接導入はできません。
VortexやModOrganizer2というMODマネージャーにこのファイルを圧縮されたまま投入するとインストール画面が表示され、導入できるようになっています。

MODマネージャーは下記より入手して下さい。セットアップ方法や使い方はWeb上に先人の方々が沢山公開して下さっています。

* Vortex(オススメ！): https://www.nexusmods.com/about/vortex
* ModOrganizer2: https://github.com/ModOrganizer2/modorganizer

それでは素敵なMODライフを！
