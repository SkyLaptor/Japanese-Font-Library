# Japanese Font Library
どのバージョンのスカイリムでも使用できる日本語圏プレイヤー向けのフォントリプレーサーです。


## 特徴
* Fomodインストーラー採用により、MOD利用初心者から上級者まで手軽に導入できます。
* 豆腐よさらば！日本で使用されるであろう文字はほぼ表示可能です。※通常サブセット版
* より安定性を求める人向けに、スカイリム標準の文字種のみに絞った軽量サブセット版も選択可能です。
* スクリプトやプラグインは使用していません。セーブデータへの影響は皆無です。
* ゲームが抱えているフォントやUI周りのバグ修正パッチもあります。


## インストール手順
VortexやMO2といったModマネージャーを用いてサクッとインストールできます。

1. インストーラーをダウンロードします。
2. Modマネージャーで導入するとインストールウィザードが起動します。
3. プリセットやオプションを選んで導入完了です。


## 独自カスタム手順
インストーラーを用いた手順ではプリセットからしか選択できませんが、フォントファイルを個別に入れ替えることで自分の好きな組み合わせを使用できます。

1. インストーラーをダウンロードし、プリセットで「フォントカスタムモード」を選択してインストールします。
2. 好きなフォントSWFとフォント設定テンプレートをダウンロードします。
3. ダウンロードしたフォントSWFとフォント設定テンプレートを、`ゲームフォルダ\Data\Interface` の中に置きます。
4. フォント設定を開き、フォント読み込み設定やフォント割り当て設定を行います。
    * フォント読み込み設定: 上部に `fontlib "Interface\フォントファイル.swf"` を追記します。
    * フォント割り当て設定: 中部にある `map "フォントマップ名" = "フォント名" Normal` を書き換えます。
        * `フォントマップ名`は変更せずに、`フォント名`の部分を変更します。
        * スタートメニュー、インベントリ、字幕といった大部分に適用したい場合は、以下のマップのフォント名を変更します。
            * $StartMenuFont
            * $DialogueFont
            * $EverywhereFont
            * $EverywhereBoldFont
            * $EverywhereMediumFont
            * $CClub_Font
            * $CClub_Font_Bold
            * Times New Roman
            * $CreditsFont
        * 主に本に適用したい場合は、以下のマップのフォント名を変更します。
            * $SkyrimBooks
        * 主に手紙やメモに適用したい場合は、以下のマップのフォント名を変更します。
            * $HandwrittenFont
            * $HandwrittenBold
5. きちんとフォント読み込み設定を行ったか、フォント割り当てを行ったかしっかり確認します。※ミスがあると全部豆腐化します。

以上でフォントが変更されます。


### フォントファイルついて
フォントファイル名、フォント名の情報はフォント設定ファイル(fontconfig.txt)内で必要となります。
当MODのフォントは、1つのフォントファイル(SWF)に対し1つのフォントを格納しています。
フォント名およびフォントファイル名は以下の規則が適用されます。

```
フォントファイル名:
fonts_<フォントファミリー>[太さ: _light | _bold]<UIタイプ: _every | _book | _handwrite>[長形: _condensed | _skinny][サブセット: _lightweight].swf

フォント名:
<フォント名>[太さ: _light | _bold]<UIタイプ: _every | _book | _handwrite>[長形: _condensed | _skinny][サブセット: _lightweight]
```

* フォントファミリー: `noto-sans` や `sourcehanserif` といった名前が入ります。
* 太さ: そのフォントファミリー内で相対的に細ければ `_light`、太ければ `_bold`が付きます。
* UIタイプ: どのUI向けに調整されているかを指します。インベントリ画面など頻繁に目につく汎用UIであれば `_every`、書籍の大部分のUIは `_book`、手紙/メモの大部分のUIは `_handwrite` となります。汎用UIは他と比較して若干大きいため、書籍に対し `_every` を使用すると違和感があるかもしれません。
* 長形: 細長さの度合いを示します。視認性は若干低下しますが、長形版を使用することでUIからはみ出てしまうのを軽減できます。通常版の横幅60-70%が `_condensed`、横幅40-50%が `_skinny` となります。
* サブセット: 「別にMOD使ってないし、使ってたとしても翻訳の際に気を付けてるよ。それよりもCTDを抑えたい。」という人向けのオプションです。バニラのスカイリムが表示可能な文字種だけに絞ることでサイズダウンした軽量版は `_lightweight` が付きます。
