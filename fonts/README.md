# フォントファイル
独自にフォントをカスタムしたい人向けのリソース。  
画像ファイルはサンプル表示。

## 使用方法
このファイルをInterfaceフォルダ内に配置した上で、フォント設定ファイル( `Interface\fontconfig.txt` または `Interface\fontconfig_ja.txt` )を開いて下記を追記する。

```:フォント設定ファイル
fontlib "Interface\フォントファイル名.swf"
```

フォントファイルの中にはフォントが一つ格納されており、格納フォントにはフォント名が定義されている。  
原則的に、フォントファイル名の`fonts_`以降がそのままフォント名になっている。

```
例1: フォントファイル名が fonts_hogehoge.swf の場合
hogehoge

例2: フォントファイル名が fonts_hogehoge_slim.swf の場合
hogehoge_slim
```

フォント名に `_slim` や `_skinny` とついているものがあるが、これは長形に加工されたバリエーションであることを示す。  
`_slim` は標準から凡そ75%の幅になっており、`_skinny` は標準から凡そ50%の幅としている。  
`_skinny` は視認性は良くないが、表示できる情報量が多いためSkyUIのMCMメニュー画面に向いている。

フォント名は以下のようにマッピングする。

```:フォント設定ファイル
map "$EverywhereFont" = "フォント名" Normal
```

まとめると、Skyrimにて任意のフォントを使用するには以下の3作業が必要である。

1. フォントファイル(.swf)を `Interface` フォルダに配置する。
2. 配置したフォントファイルをフォント設定ファイルで読み込ませる。
3. 読み込ませたフォントファイル内のフォントをマッピングする。

## 使用に関する注意点
### Interfaceフォルダ内に大量のフォントファイルを置かないこと
読み込ませていなくとも、大量にInterfaceフォルダ内にフォントファイルを置いておくとCTDが起きやすくなったり、そもそもゲームが起動しなくなったりする。使っていないフォントファイルは適宜消したほうが良い。

### 大量のフォントファイルを読み込ませないこと
CTDが起きやすくなる。使っていないフォントファイルは適宜消したほうが良い。
