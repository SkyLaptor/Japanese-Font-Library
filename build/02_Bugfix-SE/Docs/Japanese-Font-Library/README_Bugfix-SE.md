# Japanese Font Library - Bugfix SE
SkyrimSE(AE)向けのバグフィックスです。以下のバグを修正します。  

## 本UIの内蔵フォント除去
**v1.6.629以降解消していますが、下位バージョンのためにパッチしています。**  
本UI`Interface/book.swf`にはなぜかフォントが内蔵されていて、いくらfontconfig.txt側で変更してもそちらが優先されてしまいます。  
本パッチでは内蔵フォントを削除したものに置換します。  

動作確認としては「エルトリスのノート」や「アーヴェルの日記」を開いてみると良いでしょう。  
参考: https://obachanskyrim.blogspot.com/2012/07/bookswf.html  

### レベルアップメニューUI
**v1.6.629以降解消していますが、下位バージョンのためにパッチしています。**  
レベルアップメニューUI`Interface/levelupmenu.swf`にはフォントマップが正しく指定されておらず、きちんと表示されません。  
また、表示が大きくフォントによっては見切れます。  
本パッチでは内蔵フォントを削除したものに置換します。  

動作確認としては、コンソールコマンドで`advskill block 1000`を実行してレベルアップさせてみると良いでしょう。※本番セーブデータで行わないこと。
